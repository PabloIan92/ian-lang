i@N Teacher

Puerta simple para que Codex, Claude o una persona le enseñen a i@N Brain.

Flujo

1. Pedir enseñanza
Copiar una plantilla y pedirle a Codex o Claude que responda en formato i@N.
2. Guardar archivo
Guardar la respuesta como .teach o .ian en la bandeja correspondiente.
3. Importar
Ejecutar .\ian-teacher.exe importar para pasar esa enseñanza a la memoria local.

Bandejas

Codex: C:\Users\CONECTIA BA\Desktop\ian-lang\teach-inbox\codex

Claude: C:\Users\CONECTIA BA\Desktop\ian-lang\teach-inbox\claude

Manual: C:\Users\CONECTIA BA\Desktop\ian-lang\teach-inbox\manual

Formato que debe entregar Codex o Claude

# pregunta: crear una pagina web para una empresa
agente plan "Crear web de empresa" como plan
agente paso plan hacer "Crear pagina"
web iniciar "Empresa" como pagina
web titulo pagina "Empresa"
web texto pagina "Pagina generada por i@N"
web guardar pagina en "salida/empresa.html"
agente json plan como resumen
decir $resumen
