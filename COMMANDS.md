# Comandos i@N

Despues de agregar `C:\Users\CONECTIA BA\Desktop\ian-lang` al PATH, se puede
invocar i@N desde PowerShell con:

```powershell
i@n
```

Comandos disponibles:

- `i@n`: abre la consola viva de i@N.
- `ian`: ejecuta archivos `.ian` con el motor.
- `ian-agent`: genera y ejecuta programas i@N desde pedidos.
- `ian-brain`: memoria local y aprendizaje.
- `ian-teacher`: importador de enseñanzas.
- `i@n-codex`: instrucciones para enseñar desde Codex.
- `i@n-claude`: instrucciones para enseñar desde Claude.

`codex` y `claude` ya existen en esta PC. i@N no los reemplaza; los usa como
profesores externos cuando vos guardas sus respuestas en `teach-inbox`.
