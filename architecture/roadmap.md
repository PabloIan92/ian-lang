# Arquitectura Evolutiva i@N

Este mapa no copia una IA externa. Define piezas propias para que i@N crezca con control local.

## entrada

Objetivo: recibir texto humano, comandos y archivos

Version superior: entender intencion sin obligar al usuario a usar comandos rigidos

Estado actual: i@n shell

## clasificador

Objetivo: separar conversacion, accion, aprendizaje, API y codigo

Version superior: evitar mandar charla al generador de programas

Estado actual: reglas simples en ian-shell

## memoria

Objetivo: recordar enseñanzas locales

Version superior: usar memoria por relevancia, fecha, fuente y calidad

Estado actual: ian-brain

## planificador

Objetivo: convertir objetivos en pasos

Version superior: crear planes verificables antes de actuar

Estado actual: agente plan

## herramientas

Objetivo: ejecutar motor, API, red, web, mikrotik y nexos

Version superior: elegir herramienta por necesidad y explicar resultado

Estado actual: ian.exe y conectores

## supervisor

Objetivo: criticar calidad y seguridad

Version superior: bloquear o mejorar acciones flojas antes de ejecutarlas

Estado actual: ian-supervisor

## aprendizaje

Objetivo: aprender de Codex, Claude, APIs y archivos

Version superior: extraer solo conocimiento util, no ruido

Estado actual: ian-teacher y ian-daily

## autonomia

Objetivo: actuar por objetivos y registrar logs

Version superior: hacer ciclos repetibles: pensar, ejecutar, revisar, aprender

Estado actual: ian-auto

## personalidad

Objetivo: hablar de forma natural

Version superior: ser claro, breve, no robotico y admitir limites

Estado actual: ian-human

## seguridad

Objetivo: evitar daño y acciones confusas

Version superior: pedir aclaracion si hay riesgo o ambiguedad

Estado actual: reglas de supervisor
